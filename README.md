# Invoice Desk

A single-page invoice builder for time-and-materials work.

- Line items for **time** (hours as `1.5`, `1:30` or `1h 30m`), **materials**, **expenses** and **flat fees**
- Discounts, per-line taxable flags, deposits / balance due, optional grouping by type with subtotals
- Live invoice preview, PDF download (jsPDF) and standalone HTML download
- Saved invoices with Draft / Sent / Paid status and automatic overdue tracking

## Files

- `invoice-desk.html` — the source. It is also published as a Claude artifact, where invoices are saved to your Claude account.
- `index.html` — generated by `./build.sh` for the hosted site. On the hosted site, invoices are saved in your browser (localStorage).

After editing `invoice-desk.html`, run `./build.sh` and commit both files.
